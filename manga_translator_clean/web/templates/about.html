About {{ product_name }}

Project workflow, demo framing, and future-ready notes for scaling and accessibility.

Product Workflow

Detect dialogue, sound effects, signs, text, and removal regions.
OCR each detected region, translate it, remove the source text, and render the translated result back into the page.
Evaluate the detector with mAP plus class-fair macro/per-class reporting so weak classes stay visible.
Keep training, evaluation, engine diagnostics, and dataset bootstrapping behind the admin wall.

Demo Framing

Public demo: translate one page, then run a batch job.
Show the secondary colorization tab as a preserved extension point.
Admin demo: open an evaluation report and point out macro/per-class metrics for weak classes.
Admin demo: show assisted data generation with review manifests for approve / reject / uncertain image-level review.

Low-RAM and Future Scaling

Models are loaded lazily rather than all at startup.
Batch translation is processed in smaller server-side chunks and saved to disk incrementally.
Future work: queue-backed jobs, resumable batches, storage-backed manifests, and multi-machine execution.

Accessibility Reservation

Reserve future hooks for screen-reader-friendly upload/results areas.
Keep extracted and translated text structured so text-to-speech or readout support can be added later.
Future work: keyboard-first navigation, OCR readout, audio summaries, and blind-user workflows.
